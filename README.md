Репозиторий по курсу ИТиВП. 

Репозиторий разбит на 8 веток (`lab1-implementation`, `lab2-implementation`, ...), каждая ветка соответствует лабораторной работе с соответствующим номером. 
При выполнении и сдаче работы необходимо создать пулл реквест и замержить ветку в мастер ветку. До тех пор работаем в соответствующих ветках.
