# TastyBlog — Кулинарный блог о здоровом питании

Простой и семантически вёрстанный макет главной страницы кулинарного блога. Проект демонстрирует использование современного HTML, методологии БЭМ и микроразметки Schema.org.

## Особенности

- Семантическая разметка HTML5 (header, nav, section, article, footer и др.)
- Иерархия заголовков от h1 до h4
- Три изображения с корректными alt-атрибутами
- Микроразметка Schema.org для статьи (Article)
- Классы по методологии БЭМ для удобной стилизации
- Валидный код (проверен через W3C Validator)

## Технологии

- HTML5
- CSS3 (предполагается подключение внешнего файла стилей)
- Schema.org (в формате микроразметки)
